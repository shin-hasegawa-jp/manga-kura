# 重複画像検出

## 現行の保存順

1. 保存画面で同一の元ページURLを警告する。
2. 選択画像を画像プロキシ経由でBlobとして取得する。
3. Blobと寸法から登録画像モデルを生成する。
4. 作品・話・画像を1つのIndexedDBトランザクションで登録する。

## 変更範囲

- BlobのSHA-256ハッシュ生成とURL正規化
- 画像モデルへの任意の内容ハッシュ追加
- 同一バッチ内およびIndexedDB保存済み画像との重複判定
- 重複先の作品・話・画像位置を示す保存前警告

## 方針

- URL一致と画像内容一致は別の根拠として表示する。
- 画像内容はWeb Crypto APIだけで処理し、外部へ送信しない。
- 既存画像のハッシュは一括移行せず、比較時に必要なBlobだけを順次計算する。
- URL重複警告を先に確認し、その後に画像を取得して画像重複を警告する。
- 重複画像の保存を自動禁止せず、明示操作があった場合だけ継続する。
- 既存画像の上書き、統合、自動削除は行わない。
