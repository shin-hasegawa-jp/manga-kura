# 画像順の調整

## 現行フロー

1. API候補はDOM順で保存画面へ渡される。
2. 選択状態は候補オブジェクトの`isSelected`で保持される。
3. 選択候補は配列順にBlob取得され、`displayOrder`が0から採番される。
4. Repositoryと閲覧画面は`displayOrder`昇順で画像を返す。
5. 話・作品のサムネイルは最小の`displayOrder`を持つ画像を使用する。

## 仕様

- 候補一覧全体のDOM由来の表示順は変更しない。
- 選択画像だけに独立した保存順を持たせ、未選択画像は保存順に含めない。
- 再選択した画像は選択画像の末尾へ追加する。
- 上、下、先頭、末尾への移動で候補オブジェクト自体の状態を維持する。
- 調整済みの選択順でBlobを取得し、`displayOrder`を0から欠番なく採番する。
- URL・画像重複警告や保存失敗から戻っても調整済み順序を保持する。
